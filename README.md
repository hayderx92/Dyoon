# سجل الديون

تطبيق أندرويد لإدارة ديون المحل. البيانات تنحفظ على الموبايل فقط.

## الميزات
- الزبائن: إضافة وتعديل وحذف، مع بحث عربي يتحمل اختلاف الإملاء (أ/ا، ة/ه، ى/ي، گ/ك)
- تسجيل الدين والتسديد بالدينار والدولار، والرصيد يتحسب تلقائياً
- تذكير بالواتساب برسالة جاهزة فيها المبلغ المتبقي، واتصال مباشر
- كشف حساب لكل زبون مع الرصيد التراكمي، يتشارك بالواتساب
- تقارير: إجمالي الديون، حركة هذا الشهر، أعلى 10 مدينين، والمتأخرين 30 يوم أو أكثر
- نسخ احتياطي واستيراد بملف JSON

## بناء ملف APK (بدون ما تنصّب شي على حاسبتك)
1. سوِّ مستودع جديد على GitHub، مثلاً `sijil-al-duyun`.
2. ارفع كل محتويات هذا المجلد للمستودع (Add file ← Upload files)، وتأكد إن مجلد `.github` ارتفع وياها.
3. روح لتبويب **Actions**. البناء يشتغل تلقائياً، ويخلص بحدود 5 إلى 8 دقائق.
4. افتح آخر عملية بناء، ومن قسم **Artifacts** نزّل `sijil-al-duyun-apk`، وفك الضغط عنه وراح تلگه بداخله ملف `sijil-al-duyun.apk`.
5. نصّبه على الموبايل. أول مرة راح يطلب منك تسمح بالتثبيت من مصادر غير معروفة.

> **مهم:** لا تحذف ملف `keystore/release.jks`. كل التحديثات لازم تنوقّع بنفس المفتاح حتى تتنصب فوق النسخة القديمة وما تضيع البيانات.

## التعديل
كل كود التطبيق موجود بملف واحد: `www/index.html`. بعد أي تعديل، ارفع الملف على المستودع والبناء يعيد نفسه تلقائياً.
